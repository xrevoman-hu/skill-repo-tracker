# Skill Repo Tracker v1.2.5

## 中文

v1.2.5 是可执行治理与安全边界收口版。它不新增产品功能，而是把已确认的架构、Rules、ADR、高风险不变量、预算和发布实物合同转化为本地与 GitHub 都能自动执行的长期仓库机制。

### 治理与发布事实链

- **可执行治理资产**：架构、模块归属、产品与权限表面积、测试证据、高风险不变量和验证计划都由 tracked 事实源索引；修改路径会选出应复审的 Rule、ADR 和 Invariant。
- **四项精确远程门禁**：`main` 必须通过 `verify`、`coverage`、`msrv` 和 `Trusted policy / guard`。治理关键路径只能在当前 PR head 完成复审后通过，后续 push 会使旧的审查标签证据失效。
- **Dependabot 精确识别**：检查器只例外允许 GitHub 托管的 `Dependabot Updates` 动态 workflow 名称/路径组合；未知动态 workflow、缺失路径、缺失状态或未知状态都继续 fail closed。
- **单一发布事实链**：local/remote 阶段分开核对最终 commit、annotated tag、GitHub Release 元数据、资产 digest 与重新下载的 DMG，不用单一绿色结果代替产物与远程验收。

### 安全边界收紧

- Keychain 的 service 和 account 只允许既有固定 namespace，合法旧数据继续可读。
- CSP 固定 `form-action 'none'`；Tauri capability 只保留关闭保护真正使用的 event/window 权限，不增加 macOS entitlement 或新系统权限。
- 外部导航只接受无凭据、无端口的 `https://github.com` URL，并使用隔离的 browsing context。
- GitHub HTTP 只允许 HTTPS，不继承环境代理；已有 10 秒连接、30 秒普通 API 和 120 秒源码 ZIP 请求边界保持不变。

### 版本边界

- 本版不新增外部网络 API、SQLite schema、设置项、后台任务、常驻开销或系统权限。
- v1.2.4 的 Skill canonical/legacy hash 兼容与源码 ZIP 120 秒修复保持原样，不作为 v1.2.5 新功能重复声明。

### macOS DMG

本次 Release 只公开一个 Apple Silicon macOS 安装测试包：

- `Skill.Repo.Tracker_1.2.5_aarch64.dmg`

安装包采用 ad-hoc 签名，不是 Developer ID 签名，也没有经过 Apple notarization。首次启动若被 macOS 拦截，请在 Finder 中按住 Control 点击 `Skill Repo Tracker.app` 并选择“打开”，或前往“系统设置 -> 隐私与安全性”选择“仍要打开”。技术用户也可执行：

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```

## English

v1.2.5 closes the executable-governance and security-boundary work. It adds no product feature. Instead, it turns the agreed architecture, Rules, ADRs, high-risk invariants, budgets, and release artifact contract into durable mechanisms that run locally and on GitHub.

### Governance and release provenance

- **Executable governance assets**: tracked facts index architecture, module ownership, product and permission surfaces, test evidence, high-risk invariants, and the verification plan. Changed paths select the Rule, ADR, and Invariant IDs that require review.
- **Four exact remote gates**: `main` requires `verify`, `coverage`, `msrv`, and `Trusted policy / guard`. Critical governance paths pass only after review on the current PR head; a later push invalidates the previous label evidence.
- **Exact Dependabot recognition**: the checker exempts only GitHub's managed `Dependabot Updates` dynamic workflow name/path tuple. Unknown dynamic workflows, missing paths, missing states, and unknown states still fail closed.
- **One release provenance chain**: separate local and remote phases verify the final commit, annotated tag, GitHub Release metadata, asset digest, and freshly downloaded DMG. A green source check alone is not treated as proof that users receive the verified artifact.

### Tightened security boundaries

- Keychain services and accounts are constrained to the existing fixed namespace while valid legacy data remains readable.
- CSP pins `form-action 'none'`. Tauri capabilities keep only the event/window permissions used by close protection, without adding a macOS entitlement or system permission.
- External navigation accepts only credential-free, port-free `https://github.com` URLs and opens them in an isolated browsing context.
- GitHub HTTP is HTTPS-only and ignores environment proxies. The existing 10-second connect, 30-second regular API, and 120-second source ZIP request boundaries remain unchanged.

### Version boundary

- This release adds no external network API, SQLite schema, setting, background task, resident overhead, or system permission.
- The v1.2.4 canonical/legacy Skill digest compatibility and 120-second source ZIP fix remain unchanged and are not presented again as v1.2.5 features.

### macOS DMG

This Release publishes one Apple Silicon macOS test package:

- `Skill.Repo.Tracker_1.2.5_aarch64.dmg`

The package is ad-hoc signed, not Developer ID signed, and not Apple notarized. If macOS blocks the first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open, or use System Settings -> Privacy & Security -> Open Anyway. Technical users can also run:

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```
