# Skill Repo Tracker v1.2.7

## 中文

v1.2.7 是一个不新增产品功能的依赖安全与治理补丁版。它把 v1.2.6 之后已经合入 `main` 的运行时依赖修复、GitHub Actions Node 24 迁移和可执行依赖风险账本，交付到一个从最终干净 commit 重新构建并验证的 Apple Silicon DMG。

### 依赖安全与可执行治理

- **`anyhow` 安全修复**：锁文件使用 `anyhow 1.0.103`，修复 `RUSTSEC-2026-0190` 记录的 unsoundness。本项说明依赖与产物已更新，不声称漏洞已被实际利用。
- **追加式风险账本**：active 记录必须包含 package、advisory、适用 target、owner、原因、退出条件、触发器和最长 90 天复查日期；已登记风险只能退休并保留 tombstone，不能静默删除、重写或扩大。
- **完整 Security audit**：固定的 `cargo-audit 0.22.2` 先在隔离的临时 `CARGO_HOME` 中更新 crates.io index，并证明 yanked 检查与指定 lockfile 扫描实际执行；随后将 JSON 告警与 Apple Silicon macOS、Linux arm64、Linux x86_64 三份 Cargo resolve graph 双向对账。网络、解析、过滤、目标图、未知告警或账本失联都会失败。
- **保留的 Linux 风险**：`glib 0.18.5 / RUSTSEC-2024-0429` 仍是唯一 active unsound 风险，只存在于既有 Linux GTK/WebKitGTK 依赖图，不在 Apple Silicon macOS 产品图中；owner 为 `xrevoman-hu`，最晚于 2026-12-01 复查。当前 unmaintained 告警会以完整 `package@version / advisory / source` 身份报告，但不冒充已解决。本版不宣称所有 RustSec 告警清零。
- **Node 24-native Actions**：五个 GitHub workflows 已固定到 `actions/checkout` v7 和 `actions/setup-node` v7 的完整 commit SHA；Trusted policy 继续绑定最终 PR head。

### 版本边界

- 本版不改变产品行为、外部网络 API、SQLite schema、Prompt ZIP、`.srtmigration`、设置项、后台任务、常驻开销或系统权限。
- 不包含 Dependabot backlog、架构热点拆分、新功能、Developer ID、notarization、daemon 或遥测。
- v1.2.6 及更早的 tag、Release、DMG 和历史 fixture 保持不变。

### macOS DMG

本次 Release 只公开一个 Apple Silicon macOS 安装测试包：

- `Skill.Repo.Tracker_1.2.7_aarch64.dmg`

安装包采用 ad-hoc 签名，不是 Developer ID 签名，也没有经过 Apple notarization。首次启动若被 macOS 拦截，请在 Finder 中按住 Control 点击 `Skill Repo Tracker.app` 并选择“打开”，或前往“系统设置 -> 隐私与安全性”选择“仍要打开”。技术用户也可执行：


## English

v1.2.7 is a dependency-security and governance patch with no new product feature. It delivers the post-v1.2.6 runtime dependency fix, GitHub Actions Node 24 migration, and executable dependency risk ledger in a newly built and verified Apple Silicon DMG from the final clean commit.

### Dependency security and executable governance

- **`anyhow` security fix**: the lockfile uses `anyhow 1.0.103`, addressing the unsoundness recorded as `RUSTSEC-2026-0190`. This states that the dependency and artifact are updated; it does not claim exploitation.
- **Append-only risk ledger**: every active record names the package, advisory, affected targets, owner, reason, exit condition, review triggers, and a review date no more than 90 days away. A recorded risk can only retire with an immutable tombstone; it cannot silently disappear, be rewritten, or widen.
- **Complete Security audit**: pinned `cargo-audit 0.22.2` first updates the crates.io index in an isolated temporary `CARGO_HOME` and proves that the yanked check and requested lockfile scan ran. Structured JSON findings are then reconciled bidirectionally against Apple Silicon macOS, Linux arm64, and Linux x86_64 Cargo resolve graphs. Network, parsing, filtering, target-graph, unknown-warning, or ledger drift fails closed.
- **Retained Linux risk**: `glib 0.18.5 / RUSTSEC-2024-0429` is the only active unsound risk. It is reachable only through the existing Linux GTK/WebKitGTK graph, not the Apple Silicon macOS product graph; owner `xrevoman-hu` must review it by 2026-12-01. Current unmaintained warnings remain visible with complete `package@version / advisory / source` identities. This release does not claim that every RustSec warning is cleared.
- **Node 24-native Actions**: all five GitHub workflows pin full commit SHAs for `actions/checkout` v7 and `actions/setup-node` v7. Trusted policy remains bound to the final pull-request head.

### Version boundary

- This release does not change product behavior, any external network API, SQLite schema, Prompt ZIP, `.srtmigration`, setting, background task, resident overhead, or system permission.
- It does not include the Dependabot backlog, hotspot modularization, a new product feature, Developer ID, notarization, a daemon, or telemetry.
- The v1.2.6 and earlier tags, Releases, DMGs, and historical fixtures remain unchanged.

### macOS DMG

This Release publishes one Apple Silicon macOS test package:

- `Skill.Repo.Tracker_1.2.7_aarch64.dmg`

The package is ad-hoc signed, not Developer ID signed, and not Apple notarized. If macOS blocks the first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open, or use System Settings -> Privacy & Security -> Open Anyway. Technical users can also run:

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```
