# Skill Repo Tracker v1.2.1

## 中文

v1.2.1 让提示词库更适合整理、排序和分享。批量导出的提示词 ZIP 现在可以在另一台安装了 Skill Repo Tracker 的 Mac 上直接预检并导入；标签按名称匹配并自动创建，不依赖两台机器上并不一致的标签 ID。

### 更新亮点

- **可分享、可回导的提示词 ZIP**：批量 ZIP 继续保留“一篇提示词一个 Markdown 文件”，并新增只含路径、大小和 SHA-256 的 `manifest.json`。清单不保存正文，正文仍只存在于对应的 `.md` 文件中。
- **按标签文本自动合并**：导入时按去除首尾空白、Unicode NFC 和不区分大小写的名称匹配标签；本机已有同名标签时复用本机标签，不存在时自动创建。
- **导入预检和冲突保护**：导入前显示新增、相同、冲突以及标签创建/复用数量。相同 ID 但内容不同的提示词默认导入为副本；也可选择保留本机或明确覆盖，覆盖操作需要再次确认。
- **持久化手动排序**：默认按照用户调整的顺序展示提示词。支持同页精确拖放、键盘排序，以及在当前置顶或普通分组内移动到最前/最后；也可切换回“最近更新”排序。
- **更完整的标签管理**：标签面板补齐搜索、创建、重命名、同名合并和删除状态；合并或删除后会同步更新筛选、详情和编辑草稿，避免残留旧标签导致保存失败。
- **更紧凑的卡片和工具栏**：卡片可以展示更多标签，额外标签仍可在详情抽屉查看；顶部搜索和操作区占用更少高度，适合在同一屏查看更多内容。
- **更自然且可访问的交互**：点击抽屉外区域可以安全收起详情；拖放会明确显示占位槽和落点。键盘操作即时响应，并完整支持 `prefers-reduced-motion`。
- **迁移入口保持兼容**：设置页原有 v1 JSON 和 v2 `.srtmigration` 导入导出保持兼容；提示词分享 ZIP 使用提示词库页面的独立入口，不会与整机迁移包混用。

导入仅接受 v1.2.1 起生成、带 `manifest.json` 的提示词分享 ZIP。v1.2.0 生成的无清单批量 ZIP 仍可阅读其中的 Markdown，但不能直接回导，应用会显示明确提示。

提示词正文仍按原文、明文写入 Markdown。分享或导入 ZIP 前，请确认正文中没有不应交给接收者的密码、密钥或其他秘密。

### macOS DMG

本次 Release 附带 Apple Silicon macOS 安装测试包，使用 ad-hoc 签名，适合零成本测试和分享。

它不是 Developer ID 签名，也没有经过 Apple notarization。首次启动时，macOS 可能要求手动放行。

资产：

- GitHub Release：`Skill.Repo.Tracker_1.2.1_aarch64.dmg`
- SHA-256：`Skill.Repo.Tracker_1.2.1_aarch64.dmg.sha256`
- 本地构建：`Skill Repo Tracker_1.2.1_aarch64.dmg`

安装注意事项：

1. 下载并打开 `Skill.Repo.Tracker_1.2.1_aarch64.dmg`。
2. 把 `Skill Repo Tracker.app` 拖入 `/Applications`。
3. 首次启动若提示“无法验证开发者”，请在 Finder 中按住 Control 点击 App，选择“打开”，再确认“打开”。
4. 如果仍被拦截，请进入“系统设置 -> 隐私与安全性”，找到 Skill Repo Tracker 并点击“仍要打开”。
5. 技术用户也可以执行：

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```

## English

v1.2.1 makes the prompt library easier to organize, order, and share. A batch prompt ZIP can now be preflighted and imported on another Mac running Skill Repo Tracker. Tags are matched by normalized text and created when missing, rather than relying on machine-specific tag IDs.

### Highlights

- **Shareable, round-trip prompt ZIPs**: batch ZIPs still keep one Markdown file per prompt and now add a `manifest.json` containing only paths, sizes, and SHA-256 digests. The manifest does not contain prompt bodies.
- **Text-based tag matching**: import trims names, applies Unicode NFC, and matches case-insensitively. Existing local tags are reused; missing tags are created automatically.
- **Preflight and conflict protection**: preview shows new, identical, conflicting, created-tag, and reused-tag counts. A same-ID prompt with different content is imported as a copy by default; keep-local and explicit overwrite are also available, with a second confirmation for overwrite.
- **Persistent manual ordering**: prompts default to the order you choose. Same-page precision drag and drop, keyboard ordering, and move-to-group-start/end commands are supported, while “Recently updated” remains available.
- **Reliable tag management**: the anchored panel includes search, create, rename, merge, and delete states. Merging or deleting a tag also updates filters, details, and drafts so stale tag IDs cannot break a later save.
- **Denser cards and toolbar**: cards show more compact tag tokens, while the drawer keeps the complete list. Search and actions use less vertical space so more content remains visible.
- **Natural, accessible interaction**: clicking outside safely dismisses the detail drawer. Dragging shows a real placeholder and insertion target. Keyboard actions are immediate, and reduced-motion preferences are honored.
- **Migration compatibility preserved**: Settings continues to support the existing v1 JSON and v2 `.srtmigration` flows. Prompt sharing ZIPs use a separate Prompt Library entry point and cannot be confused with full-app migration packages.

Import accepts only manifest-bearing prompt share ZIPs produced by v1.2.1 or later. The Markdown files in a manifest-less v1.2.0 batch ZIP remain readable, but that older archive cannot be imported directly and the app reports this explicitly.

Prompt bodies remain verbatim plaintext inside their Markdown files. Before sharing or importing a ZIP, make sure the content does not include passwords, keys, or other secrets that should not reach the recipient.

### macOS DMG

The attached Apple Silicon macOS package uses ad-hoc signing and is suitable for zero-cost testing and sharing.

It is not Developer ID signed or Apple notarized, so macOS may require manual approval on first launch.

Assets:

- GitHub Release: `Skill.Repo.Tracker_1.2.1_aarch64.dmg`
- SHA-256: `Skill.Repo.Tracker_1.2.1_aarch64.dmg.sha256`
- Local build: `Skill Repo Tracker_1.2.1_aarch64.dmg`

Install notes:

1. Download and open `Skill.Repo.Tracker_1.2.1_aarch64.dmg`.
2. Drag `Skill Repo Tracker.app` into `/Applications`.
3. If macOS blocks the first launch, Control-click the app in Finder, choose Open, then confirm Open.
4. If it remains blocked, open System Settings -> Privacy & Security and choose Open Anyway for Skill Repo Tracker.
5. Technical users can also run:

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```
