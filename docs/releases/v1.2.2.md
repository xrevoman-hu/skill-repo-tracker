# Skill Repo Tracker v1.2.2

## 中文

v1.2.2 是提示词库的界面与状态同步修正版，重点解决标签数量必须切换 Tab 才会刷新的问题，并收敛标签编辑、工具栏和详情抽屉体验。

### 更新内容

- **标签计数立即同步**：在详情编辑器中新增、勾选或取消标签并保存后，标签管理面板会立即显示新的使用数量，无需离开提示词库。界面先使用保存响应更新，再在后台读取 SQLite 真值校正。
- **已有提示词标签编辑修复**：已有提示词可以直接勾选或取消标签，也可以在抽屉中创建新标签；新标签创建后自动选中，保存成功后卡片和详情同步更新。
- **标签管理面板可用性**：面板根据窗口与按钮位置计算可用高度，在小窗口和工具栏换行时保留标题、新建区、搜索区和首行标签，并在内部滚动。
- **一致的顶部按钮**：提示词库工具栏复用其他 Tab 的通用按钮样式，按钮字号、高度、边框、悬停和焦点状态保持一致；打开抽屉不会再压缩工具栏。
- **更轻的抽屉动效**：指针打开和关闭只保留短距离、短时长位移；键盘操作即时完成，并继续支持 `prefers-reduced-motion`。

## English

v1.2.2 is a Prompt Library UI and state-synchronization patch. It fixes tag usage counts that previously refreshed only after leaving and re-entering the tab, while tightening tag editing, toolbar consistency, and drawer motion.

### Changes

- **Immediate tag-count synchronization**: after adding, selecting, or removing tags in the detail editor and saving, Manage Tags immediately shows the current usage counts without a tab switch. The UI applies the save response first and then reconciles with SQLite in the background.
- **Reliable tag editing for existing prompts**: existing prompts can select or clear tags and create a new tag inside the drawer. A newly created tag is selected automatically, and successful saves update the card and detail state.
- **Usable tag manager sizing**: the anchored panel measures the available viewport area so its title, create controls, search field, and first row remain visible at small sizes, with internal scrolling for the list.
- **Consistent toolbar buttons**: the Prompt Library now shares the common button styling used by the other tabs. Font size, height, border, hover, and focus behavior stay stable when the drawer opens.
- **Lighter drawer motion**: pointer transitions use a short distance and duration; keyboard actions remain immediate, and `prefers-reduced-motion` is honored.
