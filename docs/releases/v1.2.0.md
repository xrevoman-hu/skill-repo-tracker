# Skill Repo Tracker v1.2.0

## 中文

v1.2.0 新增本地提示词库，把常用角色、研究方法、图像创作和写作模板放进与 Skill 管理一致的桌面工作台。它首先保护内容：详情默认只读，只有显式点击“编辑”才允许修改；长正文、批量选择和迁移也都有明确的大小与并发边界。

### 更新亮点

- **卡片式提示词库**：提示词库位于“技能”和“插件”之间，支持标签、置顶、全文搜索、30/50/100 分页和跨页选择。
- **只读详情与安全编辑**：右侧覆盖抽屉默认渲染安全 GFM Markdown；点击“编辑”后才显示原始 Markdown，未保存草稿在关闭、取消、切换条目或 Tab 时会先拦截确认。
- **原文复制与标准导出**：复制只写入原始正文；单篇导出 UTF-8 Markdown，批量导出 ZIP，文件名和 ZIP 路径都经过安全清洗与去重。
- **一致性保护**：编辑、置顶和删除使用单篇 revision；全选筛选结果使用全库 revision，数据变化时不会静默导出漂移后的集合。
- **本地检索**：标题和完整正文使用 SQLite FTS5 trigram，短关键词使用受限查询；标签筛选支持包含全部或包含任一。
- **明确的内容上限**：每篇正文最多 `5,242,880` UTF-8 bytes（5 MiB），标题最多 200 字符，每篇最多 20 个标签。
- **可选提示词迁移**：默认迁移仍保持 v1 JSON 兼容；勾选提示词后生成 v2 `.srtmigration`，导入前预检大小、引用、摘要与冲突，并默认保留本机不同内容。
- **明确隐私边界**：应用托管的 GitHub token、Keychain 数据、本地源码、源码 ZIP 和任务日志不会进入迁移包。提示词正文按用户要求逐字、明文导出；若正文中由用户粘贴了密码或凭证，它也会随正文导出，因此勾选提示词迁移时会警示并二次确认。

本次 Release 附带 Apple Silicon macOS 安装测试包，使用 ad-hoc 签名，适合零成本测试和分享。

它不是 Developer ID 签名，也没有经过 Apple notarization。首次启动时，macOS 可能要求手动放行。

资产：

- GitHub Release：`Skill.Repo.Tracker_1.2.0_aarch64.dmg`
- SHA-256：`Skill.Repo.Tracker_1.2.0_aarch64.dmg.sha256`
- 本地构建：`Skill Repo Tracker_1.2.0_aarch64.dmg`

安装注意事项：

1. 下载并打开 `Skill.Repo.Tracker_1.2.0_aarch64.dmg`。
2. 把 `Skill Repo Tracker.app` 拖入 `/Applications`。
3. 首次启动若提示“无法验证开发者”，请在 Finder 中按住 Control 点击 App，选择“打开”，再确认“打开”。
4. 如果仍被拦截，请进入“系统设置 -> 隐私与安全性”，找到 Skill Repo Tracker 并点击“仍要打开”。
5. 技术用户也可以执行：

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```

## English

v1.2.0 adds a local prompt library for keeping role prompts, research methods, image-generation instructions, and writing templates in the same desktop workbench as Skills. Content safety comes first: details are read-only until Edit is explicitly selected, while long bodies, batch selection, and migration all have bounded size and concurrency rules.

### Highlights

- **Card-based prompt library**: Prompt Library sits between Skills and Plugins with tags, pinning, full-text search, 30/50/100 item pages, and cross-page selection.
- **Read-only details and safe editing**: a right overlay drawer renders safe GFM Markdown by default. Raw Markdown appears only after Edit, and dirty drafts are guarded when closing, cancelling, switching items, or leaving the tab.
- **Verbatim copy and standard exports**: copy writes only the original body. Single export produces UTF-8 Markdown; batch export produces a ZIP with sanitized and deduplicated paths.
- **Consistency protection**: edit, pin, and delete use per-prompt revisions. Selecting an entire filtered result checks a monotonic library revision, preventing silent result-set drift.
- **Local search**: titles and full bodies use SQLite FTS5 trigram, while short queries use a bounded fallback. Tag filters can match all or any selected tags.
- **Explicit content limits**: each body is limited to `5,242,880` UTF-8 bytes (5 MiB), titles to 200 characters, and tag assignments to 20 per prompt.
- **Optional prompt migration**: migration remains compatible v1 JSON by default. Opting into prompts creates a v2 `.srtmigration` package that preflights sizes, references, digests, and conflicts, keeping different local content by default.
- **Explicit privacy boundary**: app-managed GitHub tokens, Keychain data, local source trees, source ZIP files, and task logs are excluded. Prompt bodies are exported verbatim and in plaintext; user-pasted passwords or credentials travel with the body, so opting into prompt migration shows a warning and confirmation.

### macOS DMG

The attached Apple Silicon macOS package uses ad-hoc signing and is suitable for zero-cost testing and sharing.

It is not Developer ID signed or Apple notarized, so macOS may require manual approval on first launch.

Assets:

- GitHub Release: `Skill.Repo.Tracker_1.2.0_aarch64.dmg`
- SHA-256: `Skill.Repo.Tracker_1.2.0_aarch64.dmg.sha256`
- Local build: `Skill Repo Tracker_1.2.0_aarch64.dmg`

Install notes:

1. Download and open `Skill.Repo.Tracker_1.2.0_aarch64.dmg`.
2. Drag `Skill Repo Tracker.app` into `/Applications`.
3. If macOS blocks the first launch, Control-click the app in Finder, choose Open, then confirm Open.
4. If it remains blocked, open System Settings -> Privacy & Security and choose Open Anyway for Skill Repo Tracker.
5. Technical users can also run:

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```
