# Skill Repo Tracker v1.4.1

## 中文

应用版本 `1.4.1`，适用于 macOS 12+、Apple Silicon。本版修复发布说明预检遗漏，
凭据库功能、页面和数据格式沿用 [v1.4.0](v1.4.0.md)。

- 发布流程现在会在访问远端及构建之前检查中英文分发说明；日常验证也检查当前版本说明。
  缺少必要披露时提前停止，避免上传后才被远端校验拒绝。
- v1.4.0 使用了 `notarization` 表述，未满足门禁要求的 `notarized` 字样，
  其发布后正文检查未通过。本版明确修正文案；既有 tag、Release 和说明保留，不改写历史。
- 本版重新构建并验证独立安装包；各发布层的状态以对应执行结果为准，不能仅以 Release 页面存在推断全部通过。

凭据库的 GUI、各 Agent 读取与 SSH 文件消费结果仍按实际候选和通道记录，
详见[凭据库指南与验收状态](../credential-vault.md#验收状态)。Windows 仍为 **BLOCKED**；
Claude Code 握手已验证，但模型调用因 HTTP 403 保留 **BLOCKED**。没有新增逐 Agent 权限或远程凭据服务。
升级前退出旧版并备份应用数据；凭据库须使用专用加密备份，主密码由本人保管。

### macOS DMG

分发文件为 `Skill.Repo.Tracker_1.4.1_aarch64.dmg`，仅用于 Apple Silicon、macOS 12+。
这是 **ad-hoc 签名测试分发**，不是 Developer ID 签名，未经 Apple 公证（not notarized）。

首次启动若被 macOS 拦截，在 Finder 中按住 Control 点击 `Skill Repo Tracker.app`，选择“打开”；
或前往“系统设置 → 隐私与安全性”选择“仍要打开”。钥匙串授权在系统窗口完成，不要向 Agent 提供本机密码。

## English

Application version `1.4.1` for macOS 12+ and Apple Silicon fixes a release-note preflight omission.
Credential features, pages and data formats remain as described in [v1.4.0](v1.4.0.md).

- Local release verification now checks bilingual distribution disclosures before remote access or
  building. Regular verification also checks the current version's notes. Missing disclosures fail
  before publication instead of being discovered after upload.
- The v1.4.0 notes used `notarization` instead of the gate's required `notarized` wording, so its
  post-publication metadata check failed. This version corrects that wording while preserving the
  existing tag, Release and notes.
- This version has a separate rebuild and artifact-verification process. A Release page alone does
  not prove that every release acceptance layer has passed.

GUI, Agent reads and SSH file consumption remain scoped to the candidates and channels actually
tested in the [acceptance matrix](../credential-vault.md#验收状态). Windows remains **BLOCKED**.
Claude Code's handshake was verified, but its model call remains **BLOCKED** by HTTP 403.
Per-Agent permissions and a remote credential service are outside this version.
Quit the old app and back up application data before upgrading. Use a dedicated encrypted backup
for the vault and retain its master password.

### macOS DMG

The distribution file is `Skill.Repo.Tracker_1.4.1_aarch64.dmg` for Apple Silicon, macOS 12+.
This is **ad-hoc test distribution**, not Developer ID signed and **not notarized** by Apple.

If macOS blocks first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open,
or use System Settings → Privacy & Security → Open Anyway. Complete any required Keychain
authorization in the system dialog; do not send your computer password to an Agent.
