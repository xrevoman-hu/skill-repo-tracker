# Skill Repo Tracker v1.2.9

## 中文

修复仓库列表表头全选仅选中当前页的问题。现在全选覆盖当前搜索、筛选结果的所有页；没有筛选时选中全部可选仓库。例如 60 个可选仓库、每页 15 条，一次全选后显示“备份选中（60）”。

- 翻页、排序、修改每页条数保留选择；表头选中和半选状态反映完整筛选结果。
- 取消全选只移除当前筛选范围内的选择，保留范围外已选项；“清空选择”仍清除所有选择。
- 仅 GitHub 来源仓库可选，备份仍需确认。后端接口、数据库、设置、权限和后台任务机制保持不变。
- 修正开发验证中多行语句的覆盖证据缺失：详细 V8 报告与 LCOV 对账后补充语句范围，保留原变更行分母和覆盖率阈值；未命中分支、回调和不一致报告仍拒绝通过。

### macOS DMG

唯一公开安装包：`Skill.Repo.Tracker_1.2.9_aarch64.dmg`，适用于 Apple Silicon。

安装包采用 ad-hoc 签名，不是 Developer ID 签名，也没有经过 Apple notarization。首次启动若被 macOS 拦截，请在 Finder 中按住 Control 点击 `Skill Repo Tracker.app` 并选择“打开”，或前往“系统设置 -> 隐私与安全性”选择“仍要打开”。

## English

Fixes the repository header checkbox selecting only the current page. Select all now includes every page of the current search and filters, or all selectable repositories when no filter is active. With 60 selectable repositories and 15 rows per page, one click shows “Backup Selected (60)”.

- Paging, sorting and page-size changes retain selection. The header checked and mixed states reflect the full filtered result.
- Unchecking the header removes selections within the current filter while preserving selections outside it. Clear selection still clears everything.
- Only GitHub repositories are selectable, and backups still require confirmation. Backend APIs, database, settings, permissions and task coordination remain unchanged.
- Development coverage checks reconcile detailed V8 evidence with LCOV for multiline statements while preserving the changed-line denominator and thresholds. Uncovered branches, callbacks and inconsistent reports remain rejected.

### macOS DMG

The sole public installer is `Skill.Repo.Tracker_1.2.9_aarch64.dmg` for Apple Silicon.

The package is ad-hoc signed, not Developer ID signed, and not Apple notarized. If macOS blocks the first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open, or use System Settings -> Privacy & Security -> Open Anyway.
