# Skill Repo Tracker v1.1.12

## 中文

v1.1.12 聚焦两件事：更新 Skill 时不再让本地修改陷入“覆盖或放弃”的二选一，以及让长期运行后的临时目录和仓库列表保持可管理。干净的 Skill 仍可自动更新；一旦检测到本地定制，应用会在写盘前停止，并把后续处理明确交还给用户和 Agent 工具。

### 更新亮点

- **安全处理 Skill 更新冲突**：检测到本地主库内容已修改时，应用会在下载、备份、覆盖和同步之前停止更新，不再提供“强制覆盖”或“备份后覆盖”。
- **把冲突交给用户与 Agent**：冲突弹窗、Skill 表格和详情 Inspector 会保留处理入口，任务页会持续保留“等待用户处理”记录；提示会说明可以使用 Codex、Claude Code 或其他 Agent 工具完成更新。
- **区分远端最新与本地定制**：外部处理完成后可以重新检测并确认。内容与远端一致时标记为“已是最新”，保留本地定制时标记为“已更新，含本地定制”；应用只验证文件变化和目标 SHA，不声称自动证明合并质量。
- **治理历史临时目录**：新版启动时会识别严格匹配的过期 `sync-tmp` / `install-tmp`，将旧版本未登记的目录移入应用隔离区，并在 30 天后清理；维护结果会记录为可查看的任务。
- **保护 symlink 和恢复材料**：同步目标如果是指向其他位置或断链的 symlink，会在创建临时目录前停止。需要恢复的材料不会被自动删除，跨文件系统无法原子隔离时也会保留原目录并记录人工处理路径。
- **仓库页增加客户端分页**：默认每页 15 条，可切换为 30 或 50 条；搜索、筛选和排序后再分页，页码和总数始终可见。
- **跨页选择更明确**：选中状态按仓库 ID 跨页保留，表头复选框只控制当前页可备份的 GitHub 仓库，并显示其他页已选数量。本地仓库不再出现“可以勾选但实际跳过”的歧义。
- **提升事务与并发安全**：安装、更新、同步和清理共用文件锁；冲突确认和迁移包导入使用原子事务，失败时不会留下数据库半完成状态。

## English

v1.1.12 focuses on two practical problems: preserving local Skill customizations without forcing an overwrite-or-skip choice, and keeping temporary artifacts and long repository lists manageable. Clean Skills can still update automatically. When local customizations are detected, the app stops before writing files and hands the decision back to the user and their Agent tools.

### Highlights

- **Safe Skill update conflicts**: when the local library has changed, the app stops before downloading, backing up, overwriting, or synchronizing. Destructive “force overwrite” choices are no longer offered.
- **User and Agent handoff**: the conflict dialog, Skill table, and Inspector retain clear recovery entry points, while the Tasks page keeps a persistent “waiting for user” record. The UI explains that Codex, Claude Code, or another Agent tool can be used to complete the update.
- **Latest versus customized states**: after external work, the app can re-check and confirm the result. A remote-identical tree becomes “installed latest”; a locally customized result becomes “installed customized.” The app verifies file changes and the target SHA, but does not claim to prove merge quality.
- **Stale temporary artifact cleanup**: startup cleanup recognizes strictly named expired `sync-tmp` and `install-tmp` directories. Unregistered legacy directories are moved into application quarantine and become eligible for removal after 30 days, with maintenance results recorded as tasks.
- **Symlink and recovery protection**: synchronization stops before creating a temporary directory when a target is an unrelated or broken symlink. Recovery material is retained, and a cross-filesystem quarantine failure leaves the source untouched with an explicit manual handling path.
- **Client-side repository pagination**: the repository table shows 15 rows by default, with 30 and 50 row options. Search, filtering, and sorting happen before pagination, while page numbers and totals remain visible.
- **Clear cross-page selection**: selections persist by repository ID across pages. The header checkbox controls only backup-capable GitHub repositories on the current page and reports selections on other pages. Local repositories are no longer selectable when the backup action would skip them.
- **Stronger transaction and concurrency safety**: install, update, sync, and cleanup mutations share one filesystem lock. Conflict confirmation and migration import now commit atomically instead of leaving partial database state after a failure.

Install notes:

1. Download and open `Skill.Repo.Tracker_1.1.12_aarch64.dmg`.
2. Drag `Skill Repo Tracker.app` into `/Applications`.
3. If macOS blocks the first launch, Control-click the app in Finder, choose Open, then confirm Open.

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```

- GitHub tokens remain in macOS Keychain and are never included in migration packages, SQLite, source backups, or task logs.

- This DMG is an ad-hoc testing package, not a Developer ID notarized installer.
