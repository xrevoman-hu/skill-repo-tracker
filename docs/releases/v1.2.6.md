# Skill Repo Tracker v1.2.6

## 中文

v1.2.6 是一个不新增产品功能的安全与发布门禁补丁版。它把 v1.2.5 发布后已经合入 `main` 的治理与依赖修复，交付到一个从最终干净 commit 重新构建并验证的 Apple Silicon DMG。

### 发布门禁修复

- **原生 Trusted policy job**：`Trusted policy / guard` 由默认分支的可信代码执行，并与当前 PR head 正确关联。工作流不再申请 `checks: write`，也不再手工创建可能归属到其他 Check Suite 的同名 Check Run。
- **安全审计兼容**：网络安全 lane 固定使用 `cargo-audit 0.22.2`，恢复对当前 RustSec advisory schema 的解析，不会把解析器失效误当作审计成功。
- **依赖安全升级**：锁文件将 `plist` 升级到 `1.10.0`、`quick-xml` 升级到 `0.41.0`，消除已识别的 high-severity RustSec 公告。本项修复说明的是依赖与产物已更新，不声称漏洞已被实际利用。
- **构建数据刷新**：Browserslist 的传递 lock 已刷新，避免过时数据让安全审计提前结束。

### 版本边界

- 本版不改变外部网络 API、SQLite schema、设置项、后台任务、常驻开销或系统权限。
- v1.2.4 的 Skill canonical/legacy hash 兼容和源码 ZIP 120 秒请求预算保持原样，不作为 v1.2.6 新功能重复声明。
- 历史 tag、Release、DMG 和 schema fixture 保持不变。

### macOS DMG

本次 Release 只公开一个 Apple Silicon macOS 安装测试包：

- `Skill.Repo.Tracker_1.2.6_aarch64.dmg`

安装包采用 ad-hoc 签名，不是 Developer ID 签名，也没有经过 Apple notarization。首次启动若被 macOS 拦截，请在 Finder 中按住 Control 点击 `Skill Repo Tracker.app` 并选择“打开”，或前往“系统设置 -> 隐私与安全性”选择“仍要打开”。技术用户也可执行：

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```

## English

v1.2.6 is a security and release-gate patch with no new product feature. It delivers the governance and dependency fixes merged after v1.2.5 in a newly built and verified Apple Silicon DMG from the final clean commit.

### Release-gate fixes

- **Native Trusted policy job**: `Trusted policy / guard` runs trusted code from the default branch and is correctly associated with the current PR head. The workflow no longer requests `checks: write` or manually creates a same-name Check Run that could belong to another Check Suite.
- **Compatible security auditing**: the network security lane pins `cargo-audit 0.22.2`, restoring support for the current RustSec advisory schema instead of mistaking a parser failure for a completed audit.
- **Dependency security update**: the lockfile updates `plist` to `1.10.0` and `quick-xml` to `0.41.0`, addressing the identified high-severity RustSec advisories. This states that the dependencies and artifact are updated; it does not claim the vulnerabilities were exploited.
- **Refreshed build data**: the Browserslist transitive lock is refreshed so stale data no longer aborts the security audit early.

### Version boundary

- This release does not change any external network API, SQLite schema, setting, background task, resident overhead, or system permission.
- The v1.2.4 canonical/legacy Skill digest compatibility and 120-second source-ZIP request budget remain unchanged and are not presented again as v1.2.6 features.
- Historical tags, Releases, DMGs, and schema fixtures remain unchanged.

### macOS DMG

This Release publishes one Apple Silicon macOS test package:

- `Skill.Repo.Tracker_1.2.6_aarch64.dmg`

The package is ad-hoc signed, not Developer ID signed, and not Apple notarized. If macOS blocks the first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open, or use System Settings -> Privacy & Security -> Open Anyway. Technical users can also run:

```bash
xattr -cr "/Applications/Skill Repo Tracker.app"
```
