# Skill Repo Tracker v1.2.8

## 中文

v1.2.8 汇总前端构建迁移、依赖更新和仓库开发治理，不新增产品功能。正式安装包从发布 PR 合入后的最终干净提交重新构建。

### 构建兼容与依赖

- Vite 升级至 8.2.2，迁移到 Rolldown，配套 plugin-react 6.1.1。JavaScript 与 CSS 保持 Safari 15 目标，入口补齐 `Object.hasOwn`，提供焦点样式与渐进 CSS 回退。
- 加强自包含产物、CSP、source map 和资源加载门禁，并加入 mutation/regression tests，覆盖 CSS URL、动态 DOM 资源与 React factory 旁路。
- Tauri CLI 精确升级至 2.11.4，serde 升级至 1.0.229，tauri-plugin-dialog 精确升级至 2.7.2。依赖 PR 分别完成适用的 MSRV、SQLite/Prompt fixture、App/DMG 预检与 macOS 目录选择/取消验证；正式发布仍须独立完成最终产物验收。

### 仓库 Skills 与治理

- 新增 `bugs`、`design-system-review`、`release` 三个实验性仓库 Skills，提供评测、匿名对比、信任与适用范围记录。
- Skills 路径纳入 Trusted policy，合并前必须审查最终 PR head；独立探针验证缺少审查标签时拒绝、最终 head 获审后通过。
- Skills 保持 experimental：Yao 安装模拟对空 capability 元数据的检查仍有明确阻断，原生权限执行与真实使用证据尚未齐备，不宣称完整认证。Skills 不授予自动发布权限。

### 版本边界

- 外部 API、SQLite schema、Prompt ZIP、`.srtmigration`、设置项、权限、网络 host 和后台状态保持不变。
- opener、zip、base64 的 major 升级继续延期；v1.2.7 及更早的 tag、Release、DMG 和历史 fixture 保持不变。
- 既有 Linux GTK 依赖风险继续按风险账本管理，不宣称所有 RustSec 告警清零。

### macOS DMG

本次 Release 只公开一个 Apple Silicon macOS 安装测试包：

- `Skill.Repo.Tracker_1.2.8_aarch64.dmg`

安装包采用 ad-hoc 签名，不是 Developer ID 签名，也没有经过 Apple notarization。首次启动若被 macOS 拦截，请在 Finder 中按住 Control 点击 `Skill Repo Tracker.app` 并选择“打开”，或前往“系统设置 -> 隐私与安全性”选择“仍要打开”。

## English

v1.2.8 combines the frontend build migration, dependency updates, and repository development governance without adding a product feature. The final installer is rebuilt from the clean commit produced by merging the release PR.

### Build compatibility and dependencies

- Vite 8.2.2 migrates the build to Rolldown with plugin-react 6.1.1. JavaScript and CSS retain the Safari 15 target, with an entry-point `Object.hasOwn` compatibility layer, focus styling, and progressive CSS fallbacks.
- Stronger self-contained artifact, CSP, source-map, and resource-loading gates include mutation/regression tests for CSS URLs, dynamic DOM resources, and React factory bypasses.
- Tauri CLI is pinned to 2.11.4, serde is updated to 1.0.229, and tauri-plugin-dialog is pinned to 2.7.2. Their separate PRs completed applicable MSRV, SQLite/Prompt fixture, App/DMG preflight, and native macOS directory selection/cancellation checks. Final release artifact acceptance remains a separate requirement.

### Repository Skills and governance

- Three experimental repository Skills, `bugs`, `design-system-review`, and `release`, include evaluations, anonymized comparisons, trust records, and scope boundaries.
- Trusted policy now covers Skills paths and requires review of the final PR head. A separate probe demonstrated rejection without the review label and success after review of the same final head.
- The Skills remain experimental: Yao install simulation retains an explicit blocker for empty capability metadata, and native permission enforcement and real-use evidence remain incomplete. This is not a claim of full certification, and the Skills do not authorize autonomous publishing.

### Version boundary

- External APIs, SQLite schema, Prompt ZIP, `.srtmigration`, settings, permissions, network hosts, and background state remain unchanged.
- Major upgrades of opener, zip, and base64 remain deferred. The v1.2.7 and earlier tags, Releases, DMGs, and historical fixtures remain unchanged.
- Existing Linux GTK dependency risks remain governed by the risk ledger; this release does not claim that every RustSec warning is cleared.

### macOS DMG

This Release publishes one Apple Silicon macOS test package:

- `Skill.Repo.Tracker_1.2.8_aarch64.dmg`

The package is ad-hoc signed, not Developer ID signed, and not Apple notarized. If macOS blocks the first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open, or use System Settings -> Privacy & Security -> Open Anyway.
