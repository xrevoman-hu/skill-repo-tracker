# Skill Repo Tracker v1.4.0

## 中文

**准备中**：应用版本 `1.4.0`，修订候选标识 `v1.4.0-rc.4`。本文描述候选变更，尚不表示正式
发布或验收完成；当前正式下载仍为 [v1.3.0](v1.3.0.md)。

v1.4.0 新增供本人和本机 Agent 共用的凭据库，页面沿用提示词库的卡片、筛选与详情抽屉。

- “插件”下方新增“凭据”。支持网站、SSH、数据库实例、单库账号、邮箱、TLS 证书、API Token 及通用记录，
  提供新增、查找、编辑和删除；秘密默认隐藏，查看、复制、检查文件与导出前验证主密码。
- 正式凭据和附件原字节保存在独立 SQLCipher 加密库，主密码不持久保存。人工验证绑定记录、
  版本与会话；失焦、关闭详情、切换记录或锁库使旧会话失效。原生窗口失焦同时清除页面已显示的秘密；
  安全事件监听未准备好或失败时，页面不允许读取秘密。
- Agent 共用访问码与主密码分开，由应用保存在 macOS Keychain。开启共享覆盖现有和以后新增的
  全部凭据；每次重开软件仍需人工解锁。可关闭访问或重置访问码，不需要把码粘贴进客户端配置。
- 卡片“使用”复制记录定位信息。凭据页右上角与设置复用接入说明弹窗，按 Codex、Claude Code、WorkBuddy、DeepSeek Harness
  或通用 MCP 生成单个接入说明，不携带秘密、不覆盖真实客户端配置。正式 bridge 使用固定的
  本机 STDIO 启动参数；通用选项只提供启动信息。
- SSH/TLS 等上传文件保持原字节。Agent 通过限时租约获取本机文件，用完释放；人工导出先选位置
  再验证，导出副本由用户保管。PEM 解析、配对及所提供链的本地检查不代表服务器连接或公共信任。
- 带口令私钥要求客户端提供独立标准输入或安全输入通道；口令不得进入命令文本、参数、环境变量
  或临时文件。只有命令文本接口时应报告限制并停止该步骤，不能以文件租出成功代替口令通道验收。
- 设置增加主密码修改、加密备份及恢复。备份不携带设备授权；恢复先验证预览、再明确确认替换，
  不同库身份默认关闭共享并重新建立本机授权。普通迁移包不包含凭据库。

详见[凭据库指南](../credential-vault.md)。返回给 Agent 的秘密可能保留在其上下文和历史中，
应用不能追回已交付内容。当前没有逐 Agent、逐记录权限或远程凭据服务。

### 验收与升级边界

- Windows 保留 **BLOCKED**：恢复、文件权限及原生消费未完成验收，不宣称跨平台可用。
- 当前候选的各 Agent 连接、读取和 SSH 文件消费须逐项实测；早期 E0、SDK smoke、配置结构核对
  或浏览器演示不能替代当前包的原生验收。本文不预先声明这些检查通过。
- 升级前退出旧版并备份应用数据。已有 GitHub token、普通数据库与源码备份保持原有存储边界。
  加密凭据备份需另行创建并保管主密码；降级时不要让旧应用写入它不支持的数据格式。
- 测试、主分支合入、tag、签名及远端资产检查分别记录；准备中的版本说明不等于产物已上传。

## English

**In preparation:** application version `1.4.0`, revision candidate identifier `v1.4.0-rc.4`. These notes
describe the candidate; they do not announce a release or completed acceptance. The current
release download remains [v1.3.0](v1.3.0.md).

v1.4.0 adds a credential vault shared by the user and local Agents, using the prompt library's
cards, filters and detail drawer.

- Credentials appears below Plugins. It supports website, SSH, database instance, individual
  database account, email, TLS, API token and generic records. Secrets are hidden by default; viewing,
  copying, file checking and exporting require master-password verification.
- Records and original attachment bytes use a separate SQLCipher database. The master password
  is not persisted. Human sessions bind to a record and version; blur, closing details, switching
  records or locking invalidate earlier sessions. Native window blur also clears displayed secrets;
  secret reads remain unavailable until the safety-event listener is ready and if registration fails.
- An app-managed shared Agent code lives in macOS Keychain, separately from the master password.
  Sharing covers all existing and future records. Reopening the app still requires manual unlock.
  Access can be disabled or reset without embedding the code in client configurations.
- Use copies a record locator. Credentials and Settings share the same guide dialog. The selected Codex, Claude Code, WorkBuddy, DeepSeek Harness or
  generic MCP guide contains no secrets and does not overwrite client configuration. The formal
  bridge uses fixed local STDIO launch arguments; the generic guide supplies launch information only.
- SSH/TLS files retain their original bytes. Agents obtain expiring local file leases and release
  them after use. Human exports select a destination before verification; exported copies remain
  user-managed. Local PEM parsing, pairing and supplied-chain checks do not prove connectivity or public trust.
- Passphrase-protected keys require independent standard input or a supported secure input channel.
  Passphrases must not enter command text, arguments, environment variables or temporary files.
  Clients with only a command-text interface must stop this step and report the limitation.
- Settings add password changes, encrypted backup and recovery. Backups exclude device authorization.
  Recovery verifies and previews before confirmed replacement. A different vault identity disables
  sharing and requires new local authorization. Normal migration packages exclude the vault.

See the [vault guide](../credential-vault.md). Returned secrets may remain in Agent context and
history and cannot be recalled. Per-Agent permissions, per-record permissions and a remote service
are outside this version.

### Acceptance and upgrade boundaries

Windows remains **BLOCKED** for recovery, permissions and native file consumption. Each client's
connection, reading and SSH file consumption must be tested against the current candidate. E0,
SDK smoke, schema review and browser demos do not establish current native-package acceptance.

Quit the old version and back up application data before upgrading. GitHub tokens, the ordinary
database and source backups retain their storage boundaries. Create credential backups separately
and retain their master password. Do not use an older app to write an unsupported data format.
Tests, main-branch merge, tags, signatures and remote artifacts are separate acceptance steps.

### macOS DMG

No DMG download has been published for this version. The target remains Apple Silicon, macOS 12+,
with **ad-hoc test distribution**, not Developer ID signing or Apple notarization.

If macOS blocks first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open,
or use System Settings → Privacy & Security → Open Anyway. Complete any required Keychain
authorization in the system dialog; do not send your computer password to an Agent.
