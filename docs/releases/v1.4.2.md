# Skill Repo Tracker v1.4.2

## 中文

应用版本 `1.4.2`，适用于 macOS 12+、Apple Silicon。本版改进任务失败诊断：

- 备份失败日志保留错误原因、错误码和详情；Skill 安装、更新的早期失败也留下审计记录。
- 检测全部失败时正确归入“失败”，便于筛选定位。
- 旧名和新名仓库记录指向同一远端时，各自生成独立备份文件，避免重复文件名导致备份失败。
- 任务详情提供可键盘访问的入口、可换行日志和历史日志缺失说明。
- 复制任务包含对象、状态及完整日志；复制失败明确反馈，不再误报成功。
- 请求失败后保留可查看的诊断信息，读回任务仍遵守现有并发和过期结果规则。
- 修复依赖审计发现的问题：实际数据库引擎升级到 SQLCipher 4.20.0 / SQLite 3.54.1，配套 rusqlite 0.41.1，并定点更新 Tokio、Quinn、rustix 与开发依赖 undici。构建 MSRV 为 Rust 1.89.0。

旧任务当时未保存的错误详情无法恢复；可从来源页面重新执行，以取得新日志。
未增加数据库迁移、后台服务或系统权限。候选验证与正式发布状态分别记录。

### macOS DMG

正式分发文件名为 `Skill.Repo.Tracker_1.4.2_aarch64.dmg`；候选批次使用单独的 RC 文件名和 tag。
这是 **ad-hoc 签名测试分发**，不是 Developer ID 签名，未经 Apple 公证（not notarized）。

首次启动若被 macOS 拦截，在 Finder 中按住 Control 点击 `Skill Repo Tracker.app`，选择“打开”；
或前往“系统设置 → 隐私与安全性”选择“仍要打开”。钥匙串授权在系统窗口完成。

## English

Application version `1.4.2` for macOS 12+ and Apple Silicon improves task failure diagnostics:

- Backup failures retain the error message, code and details. Early Skill install/update failures
  also leave an audit record.
- Repository checks with no successful result are classified as failed.
- Repository records that resolve to the same renamed remote get distinct backup filenames.
- Task details support keyboard access, wrapped logs and an explanation for missing historical logs.
- Copy includes the task target, status and complete log. Clipboard failures are reported accurately.
- Failed requests retain inspectable diagnostics; persisted-state refreshes respect existing
  single-flight and generation boundaries.
- Address audited dependency issues with SQLCipher 4.20.0 / SQLite 3.54.1, rusqlite 0.41.1,
  and targeted Tokio, Quinn, rustix and development-only undici updates. Build MSRV is Rust 1.89.0.

Details that were not saved by older tasks cannot be recovered. Run the operation again from its
source page to collect a new log. No database migration, background service or system permission
is added. Candidate validation and formal release status are recorded separately.

### macOS DMG

The formal distribution filename is `Skill.Repo.Tracker_1.4.2_aarch64.dmg`; candidates use separate
RC filenames and tags. This is **ad-hoc test distribution**, not Developer ID signed and
**not notarized** by Apple.

If macOS blocks first launch, Control-click `Skill Repo Tracker.app` in Finder and choose Open,
or use System Settings → Privacy & Security → Open Anyway. Complete Keychain authorization
in the system dialog.
