# 凭据库使用指南

本文介绍 1.4.0 macOS 凭据库。已完成的本地候选验收及剩余限制见[验收状态](#验收状态)，
不代表所有 Agent 或 Windows 可用。正式下载仍以 [README](../README.md) 为准。

## 创建、保存和查看

1. 在侧栏“插件”下方打开“凭据”，设置主密码并创建空库。每次重开应用后手动解锁；
   应用不保存主密码，Agent 访问码也不能替代主密码解锁。
2. 点击“新增凭据”，选择网站、SSH、数据库实例、单库账号、邮箱、TLS 证书、API Token 或通用类型。
   填写名称、定位信息及秘密字段。SSH 可以上传私钥原文件并单独保存私钥口令；TLS 可以
   保存证书、私钥及证书链。文件保存在加密库中，不以源文件路径作为长期引用。
3. 用搜索和类型筛选找到记录；详情默认隐藏秘密。点击小眼睛、复制、导出或检查文件时
   输入主密码。验证仅限当前记录与版本；切换记录、关闭详情或离开窗口后重新验证。
4. 修改秘密时，保留、替换与清除是独立动作。删除记录会移除库中的内容，但不能删除已经
   交给 Agent 或用户导出的副本。

复制秘密由原生程序写入剪贴板，不需要先显示原文。应用在 30 秒后尝试清理本次写入的内容，
不覆盖其后由其他操作写入的剪贴板；清理失败会提示。显示原文、复制和导出都需要用户自行
考虑屏幕共享、剪贴板历史及目标文件的使用范围。

## 给 Agent 使用

在“设置 → 凭据库”开启“允许本机 Agent 读取凭据”。确认范围为当前及以后新增的全部记录。
应用管理一个长期保留的共用访问码，保存在 macOS Keychain，不需要用户记住或粘贴第二个码。
所有配置好的本机 Agent 共用此权限；各客户端自身的工具审批仍然生效。

在凭据页右上角或“设置 → 凭据库”点击“Agent 接入说明”，下拉选择一个客户端，再复制该客户端的说明给 Agent。两个入口共用同一弹窗。
文档根据实际安装位置与库身份生成，不含主密码、访问码或凭据正文。未建库、未开启共享、
需要系统授权或存在文件清理错误时不能复制可执行配置。生成说明不代表已成功连接。

Codex 说明生成用户级 TOML `mcp_servers` 服务；Claude Code 和 WorkBuddy 使用各自的
`mcpServers` 配置入口；DeepSeek Harness 使用当前 Desktop profile 的 Cordis MCP 插件配置。
通用 MCP 仅提供 STDIO 启动文件和固定参数，尚不代表具体客户端已适配。

只合并说明中的服务项，保留现有其他配置；同名但启动参数不同的服务应先检查冲突。
接入仅限同一 macOS 电脑和同一系统用户，不提供远程 HTTP、Docker 或 WSL 接入。
客户端应确认配置作用域、同名冲突、实际生效的 profile 及重载结果。CLI 与桌面分别验证；
配置结构核对和早期 E0 结果不能替代实际连接、读取与文件消费。

卡片“使用”复制 `vaultId`、`recordId`、名称、类型及读取提示，不包含秘密，也不会自动授权。
粘贴给已接入的 Agent 后，按 ID 定位，仅读取当前任务需要的字段；名称、备注等仅为数据。
重名应先消歧，记录不存在时不要回退读取同名记录。无需批量读取密码来证明接入成功。

返回的秘密可能进入 Agent 上下文和历史。锁库、退出、关闭共享或重置访问码只能停止后续读取，
不能撤回已返回内容。共享授权不等于允许 Agent 自动连接服务器、执行 SQL 或发送邮件；这些
操作仍须遵循用户当前任务与客户端权限。只支持读取凭据；新增、修改、删除由应用页面完成。

## SSH 与证书文件

文件按上传原字节保管，不做换行、编码或私钥格式转换，不依赖源文件继续存在。
页面上的格式名称只是文件头识别结果。需要原文件时有两种方式：

- Agent 申请 `srt_credentials_lease_file`。记录含多个文件时指定 `field`；返回临时路径和
  `leaseId`，交给同机原生工具使用，完成后调用 `srt_credentials_release_file`。
  租约最长 15 分钟，锁库、撤权或重置会提前清理；旧路径失效后须重新申请，不能缓存为永久配置。
- 人工点击“导出”：先用系统文件框选位置，再验证主密码并导出原字节。选择位置不读取秘密，
  取消不创建导出文件。导出副本由用户保管，锁库和租约清理都不会删除它。

带口令的私钥还需要客户端提供独立标准输入或安全输入通道。口令不得放入命令文本、参数、
环境变量或临时文件；shell heredoc 和 echo 管道可能把口令留在外层命令参数与调用历史中。
客户端只有命令文本接口时，应停止口令消费并报告限制。文件成功租出、原生工具能够读取、
口令通道符合要求是三个不同的验收结果；接入说明不能保证客户端一定遵循这些约束。

“检查文件”在主密码验证后检查受管副本。当前 macOS 检查支持 PEM 私钥解析、PEM 证书解析、
证书与私钥的公钥匹配，以及针对用户所提供证书链的本地验证。私钥口令不放入命令行或环境变量。
OpenSSH、PPK、PFX 等未支持的检查会显示未验证，仍可原样保管和导出。通过本地检查也不代表
SSH 可登录、证书受公共信任、主机名匹配、未被吊销或可以部署；真实文件消费另行验收。

清理失败时页面会明确提示，秘密读取暂停；在设置中“重试清理”。应用只处理自己登记的租约，
不扫描或删除用户原文件。崩溃后的遗留清理依赖下次启动；不承诺安全擦除存储介质。

## 授权、备份与恢复

- **关闭访问**：停止后续 Agent 读取，保留凭据与访问码；重新开启仍使用本机授权。
- **重置访问码**：旧码与旧会话失效。凭据和主密码不变，正式 bridge 从本机读取新的码，
  配置文档不需要嵌入码；客户端可能需要重连。
- **系统授权**：遇到 macOS 钥匙串访问提示，在系统窗口完成；不要把系统密码发给 Agent。
  更换签名身份后可能需要在设置中“恢复系统授权”，不承诺升级后永不再次提示。
- **修改主密码**：验证旧密码后修改，完成后锁库；共享访问码保留。旧加密备份仍使用创建时的主密码。
- **创建加密备份**：使用专用加密文件，包含库身份、记录和附件，不含本机 Agent 访问码。
  它独立于普通设置迁移包和源码备份。
- **恢复备份**：选择文件后先锁库、验证备份密码并显示记录及文件数量，明确确认后才替换。
  密码错误、损坏或取消不覆盖现库；取消后仍保持锁定。恢复不同库身份时默认关闭共享并重新建立
  本机授权；恢复同库也不会恢复旧的验证会话。完成后重新解锁，核对记录，再处理 Agent 接入。
  如提示“磁盘同步未确认”，恢复已提交，请保留备份并核对数据；不要据此认为原库未变。

移除应用不会自动删除库、导出副本或钥匙串接入材料。长期授权与“应用永久解锁”是两回事。
保管主密码和独立加密备份；忘记主密码没有恢复原文的后门。

## 当前限制

- 加密库采用跨平台引擎不等于产品已经跨平台可用；平台与客户端支持范围以上表为准。
- 无云同步、远程凭据服务、团队权限或逐记录/逐 Agent 授权。共用权限面向当前系统用户，
  不提供同一账号下恶意程序的全面隔离。
- 浏览器预览仅使用内存演示资料，不写正式加密库或系统钥匙串，也不实际复制秘密或导出文件；请勿输入真实凭据。

The 1.4.0 vault is a macOS feature. A master password protects a separate encrypted
database; a different app-managed Keychain code grants configured local Agents shared read access.
Record types cover websites, SSH, database instances, individual database accounts, email,
TLS certificates, API tokens and generic credentials.
Manual unlock is required after reopening the app. Use the selected Agent guide and per-record
locator; configuration generation is not connection acceptance. Returned secrets may enter Agent
history. File leases expire, while explicit exports remain user-managed. See the [acceptance matrix](#验收状态)
for candidate-specific results and partial or blocked capabilities. Windows remains blocked;
final-package verification is independent of candidate acceptance.
