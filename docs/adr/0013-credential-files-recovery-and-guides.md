# ADR 0013：凭据文件、恢复与正式本机接入

- 状态：Accepted
- 承接 ADR 0010–0012；macOS 产品补齐文件与恢复，Windows 继续单独阻断。沿用卡片、单抽屉与设置行，不引入新界面框架、逐客户端授权表或后台 daemon。
- 人工原件导出先用原生保存对话框选择位置，再验证当前记录。GUI 保存单次选择的 opaque 标识与记录/版本/字段绑定，不接受 WebView 传入路径。后端只经私有控制管道交付原字节；GUI 在写入秘密前持久登记 0600 临时文件及父目录身份，复核目标及交付代次后原子提交。取消、失败与重启只清理身份匹配的登记暂存；清理失败锁库并提供重试。用户导出件不由租约或暂存清理删除。
- 备份为独立 SQLCipher 数据库文件，含格式、库 ID、记录和附件，不包含主密码、设备访问码或受管临时路径。大小有界，先创建一致快照并验证，再发布。修改主密码在新加密副本完成并验证后原子切换，不额外生成旧密码副本，失败保留旧库和旧密码，不重置 Agent 码；已有备份及恢复历史副本仍使用各自创建时的密码。
- 恢复开始锁库；密码/格式/完整性校验及摘要在私有暂存进行，确认前不替换现库。已有库先保留加密可恢复副本，切换由受管事务记录保护；重启只恢复明确登记的事务，不按文件名猜测删除。同机同库保留本机共享意图与码，不同库默认关闭共享；恢复后保持锁定并重启宿主绑定库身份。根锁覆盖恢复、标记和 socket 启动，避免多个宿主并发切换。
- 恢复在删除回滚记录前仍可失败并回滚；删除记录为提交点。提交后的目录同步失败必须报告“已恢复、磁盘同步未确认”，继续更新库身份、撤销不同库的旧共享并重启宿主，不得误报原库未变。警告跨宿主重启保留，用户保管的备份及加密恢复副本不自动删除。
- MCP 文件租约可显式选择字段；多附件未选字段必须消歧，不默默选第一份。清理失败保持拒读，并提供重试入口。格式标记、解析/配对、实际工具消费分别报告；不重写原件或移除其口令保护。
- 启动时仅对已有正式库启动锁定宿主，持有根锁后清理登记的租约和导出暂存；无库仍惰性初始化。有效账本清理失败保留条目、剩余数量与重试入口，拒绝解锁和读取；非法账本拒绝启动并保留原件。此处收窄调整 ADR 0012 的惰性启动，不新增 daemon、自动解锁、交互式钥匙串访问或空库创建。
- 文件检查仅允许固定 macOS `/usr/bin/openssl` 的已审查解析/公钥/配对参数；输入来自本产品已登记的只限本人访问的租约。口令只经私有 stdin，不进 argv、环境或日志；stderr 丢弃，输出有界，只返回非秘密状态。子进程有超时、kill/wait 回收；不接网络，不执行 Shell，不把格式匹配说成服务器可连接或证书获互联网信任。
- 正式 STDIO 入口 `--credential-mcp --root <path> --vault-id <id>` 验证固定参数与正式库标记，不启动 GUI/建库/自动解锁。五种说明由当前可执行文件、应用数据目录与状态生成，仅包含所选客户端配置；未就绪不输出可执行占位配置，客户端配置合并/版本兼容与真实工具验收分别记录。
- 原普通数据库、GitHub token 和非敏感迁移包不变。新增文件/进程/路径/动作均精确登记与负向测试；不全局放宽 Shell、任意路径或安全存储权限。
