# ADR 0012：凭据库的人工存取与 GUI 进程边界

- 状态：Accepted
- 承接 ADR 0010/0011 的 SQLCipher 与本机授权决定；E0 的合成库和实验入口保持独立，
  正式库不导入实验记录。Windows 与正式 Developer ID 升级仍须独立验收。
- 正式 GUI 仅在凭据功能被访问时启动同一可执行文件的专用宿主子进程。程序路径来自
  `current_exe`，固定模式、专用应用数据目录及参数；不接受任意可执行程序、Shell 或环境
  拼接。私有 stdin/stdout 传递本地主密码与人工动作，不把它们放在 argv、日志或 MCP。
  GUI 实际退出事件条件清除自有剪贴板；独立的 250 毫秒父进程检查确保系统授权阻塞时
  宿主也会随 GUI 退出，不创建开机 daemon。Keychain 交互仍仅在子进程，
  不改变 GUI 中原 GitHub adapter 的进程级交互行为。
- 正式凭据库独立保存秘密、元数据及文件原字节，创建后为空；原普通 SQLite、提示词、
  任务日志和非敏感迁移包均不增加凭据。库格式和记录版本显式校验；失败保存和版本冲突
  不覆盖旧记录。字段修改区分保留、替换和清除，不通过读取旧秘密预填编辑表单。
- 人工查看与复制必须经后端主密码验证，绑定记录 ID、版本、库与详情会话代次。切记录、
  关抽屉、离页、窗口失焦、锁库或更新记录使会话失效；迟到响应不可显示或写入剪贴板。
  解锁库不等于人工查看验证，Agent 码也不能替代主密码。
- macOS 秘密复制使用原生剪贴板变更标识与本次内容共同确认归属。30 秒或锁库时仅清理
  本次写入，后来即使复制相同文字也不能被旧清理误删；无法确认或清理失败必须如实反馈。
  不含秘密的记录使用指令使用普通复制，不建立秘密清理任务。
- 前端通过现有 AppService 和唯一 api wrapper 接入；Demo 只处理合成数据，不宣称加密、
  原生剪贴板或真实 MCP 已完成。沿用提示词页卡片和单抽屉，不新增 UI 框架或权限树。
  纯类型和字段策略放在不依赖视图或 adapter 的 frontend-contract 层；私有控制协议由
  library 唯一声明供同包 binary 共用。GUI 管道限 160 MiB 以覆盖 16 MiB 文件的 JSON
  转义；MCP/本地 IPC 仍限 24 MiB，按完整 envelope 检查并返回可恢复错误与文件租约提示。
- E1 覆盖人工存取；文件导出、备份恢复和正式客户端配置按后续阶段兑现。未就绪的入口
  显示实际原因，禁止提供看似可执行的占位配置。任何局部完成不取消 Windows 阻断。
- 新进程、命令、文件、原生剪贴板与前台清理任务逐调用点登记，附负向测试；不全局
  放宽 Command、Keychain、文件系统或外部网络权限，也不提高已有热点预算。
